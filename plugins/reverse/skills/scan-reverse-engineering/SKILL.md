# Scan → CAD reverse engineering (ScanRuler)

The guide for this lives in ScanRuler itself, written for the build you are connected to — this file only points at it, so it is never out of date.

1. `scanruler_status`; no page connected → `scanruler_open`.
2. Read the guide, whole, before the first step: `guide_read { topic: ["model", "scan-to-cad"] }`.
3. Follow it. It sends you to sections of `model-reference` when you need them — `guide_read {}` lists every guide and section with what each costs.

A page with no `guide_read` tool is a build from before the guides: say so, and work from the tools' own descriptions.
