# Mold Making workspace

Native ScanRuler workspace for manufacturing mold tooling from imported STL, OBJ, PLY, 3MF and CAD STEP/STP solids. Target import, project persistence, the mesh worker, Manifold booleans, mesh offsets, and STL/3MF export use existing ScanRuler infrastructure.

## Workflows

- **Direct-print rigid molds:** The default makes **two full-height, separate manifold pieces** divided at an adjustable plane (X, Y or Z; plane fraction 0.1–0.9). Four pieces use an additional perpendicular plane. The original target cavity is subtracted BEFORE splitting, so geometry above the parting plane is retained. Only the explicitly selected one-piece setting is a truncated open impression.
- **Silicone containment boxes:** rectangular or **cylindrical**, with printed base, wall thickness, silicone space, and **interior box-wall draft** (0–12°). Supports one, two or four components using the same split logic. A master must be held in place and sealed before pouring silicone. Box registration is on external wall bosses rather than the single bottom plate, keeping upper walls aligned.
- **Thin conformal negative shells:** offset outer cavity shells; two/four-piece splitting now preserves the *full model height* by default. Thin shells use the same sampled spherical distance-field dilation for their outer and inner surfaces. Details smaller than the selected grid spacing are not guaranteed. No registration pins yet on thin shells.
- **Mating features:** choose **tapered printed keys** (default), straight printed pins, or **paired blind clearance sockets for purchased metal dowels** (no printed pins). Registration diameter, depth and radial clearance are configurable. Default automatic placement distributes up to **five keys per seam**, reducing the count when smaller split interfaces cannot safely accommodate them. Alternatively, manual placement exposes editable key positions as percentages of the shared seam span, with add/remove controls and explicit collision errors. Coordinates are applied to every applicable split interface, not yet independently per interface; direct dragging in the viewport remains planned under #12. Direct-print mold keys are placed in the solid backing below the cavity. Silicone buckets instead add solid **exterior wall bosses** at the ends of each parting seam, at two different heights by default, then form printed pins or blind dowel sockets in those bosses. Manual key percentages on silicone buckets adjust boss **heights**, not the old bottom-of-box seam positions. Four-part buckets assign bosses to each quadrant's exterior edge. Too-thin or narrow seams are rejected rather than silently omitted. Four-part Z-first keyed splitting is not supported.
- **Opaque preview:** each STL is a separate closed geometry component. The viewport shows a solid (not translucent) rendering; the exploded gap can be adjusted to zero to assemble the virtual halves.
- **Export:** a **separate STL for each part** or a **single 3MF with separately positioned parts** on a printable plate. Never concatenate coincident mating planes into one STL. Materials/triangles and per-part warnings are shown before exporting.

## Fidelity and draft notes

Default cavity clearance is **0 mm**, retaining the source facets exactly. Positive clearance now uses a **sampled spherical Minkowski dilation**: the solid's signed Euclidean distance is evaluated against its original triangles (using an accelerated triangle BVH) and fed to Manifold 3.2.1's `levelSet` mesher at a negative iso-level. This rounds sharp corners instead of moving individual vertices along averaged normals, and is used for both the direct mold cutter and the inner/outer shells. The reported grid spacing and refinement tolerance are important: this is **not an exact analytic CAD offset** and may lose sub-grid features. To avoid excessive browser memory usage and slow sampling, **Balanced** (default) caps sampling at approximately **850,000 cells** (previously 8 million); **Fast** targets 200,000 cells for previews, while **Fine** allows up to 6 million for higher detail. The actual grid spacing depends on model dimensions and is printed in generated warnings. Each setting also scales the level-set refinement tolerance. Thin shells reuse a single triangle BVH for both surface offsets instead of building it twice. Models exceeding the chosen budget and maximum grid spacing fail explicitly rather than silently returning the old jagged normal-offset geometry. The synchronous Manifold level-set callback runs within the existing mesh Web Worker; it is not parallelized, and multithreading would require a separate SDF sampling/data-flow design rather than simply spawning more UI workers. The source is never modified. OpenCascade's B-rep offset algorithm is not used here because the mold worker receives a tessellated mesh even when the source originally came from STEP. Native Manifold Minkowski sums arrived after the project's pinned Manifold 3.2.1, and the newer implementation is still computationally expensive for very dense, nonconvex inputs. High-fidelity preservation for extremely small features still needs a production CAD/SDF offset implementation. 


Generated CSG/level-set mold parts are checked separately from the imported master. If Manifold's mesh export creates a zero-area triangle (even when the master is valid and source repair is enabled), the export stage first tries a topology-preserving vertex adjustment of at most 0.001 mm, then native Manifold simplification at 0.00001 and 0.0001 mm. It accepts only a closed, positive-volume mesh with material-volume change below a strict tolerance; otherwise the output is rejected with an output-specific error. The source-repair toggle does not control this generated-mesh cleanup.

Four-piece molds are now partitioned completely **before** their registration features are added, so a second split does not shear pins installed on the first seam. Extremely skinny but nonzero-area triangles on parting faces are accepted. Mold Making now offers **Repair small mesh defects** (enabled by default): it works only on a temporary target copy, preserves closed source topology by lifting collapsed triangle vertices by at most **0.001 mm** (no dropped faces), and, on open targets, also attempts the same connectivity-preserving lift before any face removal; only if lifting is impossible does it remove **exactly zero-area triangles** and join **exactly coincident** vertices if that improves watertightness, and tries Mesh Tools' flat then curved hole-filling algorithms and validates the patched triangles for zero area to patch only complete boundary loops smaller than the **Max repair hole size (mm)** control (default 2 mm). A full report of what changed appears in generated warnings; **the scan, imported file, and STEP reference are not altered**. Larger rims, broken edge chains, nonmanifold edges and failed patches still block generation for **direct-print molds and thin conformal shells**; the **silicone containment box only uses the model's bounding coordinates** and requires no manifold/watertight target or repair pass. Do not increase the hole limit blindly: any patch is a guess at missing source material. For deliberate edits, use **Mesh Tools → Fill holes → Use for analysis**, or repair the mesh externally. Independent tooling components must still be contiguous. Only microscopic isolated Boolean debris (under 0.5 mm³ and under 0.001% of a component's volume, with a 1 mm³ aggregate cap) can be omitted with an explicit warning; material-size disconnected fragments remain a hard error with per-island volume diagnostics. The Mold Making panel wraps tool-choice button labels, long setting names and errors within the panel width. See #32 for regression coverage on production models. Thin conformal shells use the same spherical distance-field offset for their wall thickness and must still be inspected for small details and disconnected thin regions.

The **box draft** angle only applies to the containment box's *inner walls*. **Proper part-surface draft and undercut removal for rigid molds are not implemented yet**. Parting by itself does not make every shape demoldable; it may require additional/manual splits, vents/sprues and draft. Pins and splits do not act as liquid seals. A castable fully-enclosed direct mold normally needs a sprue and vents, which remain on the roadmap.

## Local verification

```sh
npm ci
npm run build
npm test
node scripts/check-plugin-boundary.mjs
npm run dev
```

Open the local build (not scanruler.com), select **Mold Making**, and import [cube-10mm.stl](fixtures/cube-10mm.stl). Generate a two-part direct mold with **0 clearance**; both STL files should be closed solids and cover the full 10 mm target height. Generate four parts and inspect each. Compare tapered and straight printed pins, then select metal dowel sockets and verify that both halves have holes (not pins). Try manual key fractions 25% and 75%, and verify the cavity is unchanged. For the four-piece test, check that each interface has registration without keys cutting across the other split. Then change to a circular silicone box, set 2° draft and 2 parts, and inspect the bottom, open top and matching split. Open the 3MF in a slicer and check that all its parts are spaced apart. Repeat with a watertight STEP part and a model with slender features.

There are committed regression tests for these cases, **but they are not a substitute for a locally executed build and physical slicer/print QA**.

## Known limitations

Arbitrary rotated/curved multi-plane parting, 3D-draggable/per-seam registration, model-aware keys, sprues/vents, clamps, channels, draft on the casting surface, extraction/undercut analysis, self-sealing master mounts, and high-fidelity detail-preserving conformal offset are still open issues. Production mold release and material compatibility are user responsibilities.

Full feature tracking: [docs/mold-making-issues.md](../../docs/mold-making-issues.md). In particular, #6, #7, #8, #10, #11, #12, #13, #14, and #25.
